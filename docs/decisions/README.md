# Decision records

Dated records of decisions and deviations, written at the moment they happen.
One file per decision, numbered, never edited after the fact except to add a
"Superseded by" line. If a later decision reverses one of these, it gets its
own record and links back.

Format: **Context** (what forced the decision), **Decision** (what we chose),
**Why** (the mechanism, not just the conclusion), **Consequences** (what this
makes easier or harder, and what would overturn it).
